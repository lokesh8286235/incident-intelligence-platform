# AETHER Status

This repository currently contains the architecture, evaluation specification, contribution guidance, and project documentation for AETHER.

The implementation is intentionally not represented as complete production software in this repository yet.

## Evidence policy

Project metrics are reported evaluation results and should be treated as reproducible claims only when the corresponding implementation and benchmark artifacts are present.

## Next engineering milestones

- Implement ingestion and normalization interfaces
- Implement retrieval and evidence-correlation pipeline
- Add a local deterministic evaluation harness
- Add unit and integration tests
- Add a minimal operator API
- Add a reproducible demo dataset
- Add CI for linting, tests, and evaluation regression
