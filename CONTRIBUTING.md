# Contributing

Thanks for helping improve AETHER.

## Development

1. Create a focused branch for your change.
2. Keep changes small and testable.
3. Add or update tests for behavior changes.
4. Document meaningful architecture or evaluation changes.
5. Run the project's test and lint commands before opening a pull request.

## Pull Requests

Please include:

- What changed
- Why it changed
- How it was tested
- Any performance or evaluation impact
- Screenshots for UI changes

For model or retrieval changes, include the relevant evaluation results and note any dataset or configuration changes.
